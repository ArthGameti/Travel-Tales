# 🌍 Travel Tales – MERN Stack Travel Story Platform

Travel Tales is a full-stack MERN web application that allows users to share, explore, and engage with travel stories. The platform enables users to create stories with images and videos, like stories, search and filter content, and securely manage their own travel experiences. The application focuses on performance, security, and a smooth user experience.

This project was developed as part of the Bachelor of Engineering (Information Technology) curriculum at Vishwakarma Government Engineering College, Ahmedabad.

---

## 📌 Project Overview

Travel Tales is designed for travel enthusiasts who want to document their journeys and explore experiences shared by others. The platform works like a social storytelling application where users can publish travel stories, interact with content, and discover destinations through shared experiences.

---

## 🚀 Features

### 🔐 User Authentication
- Secure user registration and login
- JWT-based authentication
- Password encryption using bcrypt

### ✍️ Story Creation
- Create travel stories with title, description, and location
- Upload images and videos
- Select publishing date and time

### ❤️ User Engagement
- Like your own and other users’ stories
- View stories with rich media support

### 🔍 Search & Filter
- Search stories by title, description, or location
- Filter stories by date

### ✏️ Story Management
- Edit or delete your own stories
- Protected access to user-specific content

### 📱 Responsive Design
- Fully responsive UI for mobile, tablet, and desktop devices

## 🛠️ Technology Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Toastify
- Moment.js

### Backend
- Node.js
- Express.js
- JSON Web Tokens (JWT)
- bcrypt
- Multer (for image and video uploads)

### Database
- MongoDB

---

## 🧩 System Architecture

- React frontend communicates with backend using REST APIs
- Express.js handles server-side logic
- MongoDB stores users, stories, likes, and media metadata
- JWT ensures secure authentication and authorization
- Multer manages image and video uploads
